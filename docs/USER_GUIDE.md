# 사용자 가이드

이 문서는 개발 지식이 없는 사용자가 `excel-validator-gui.exe`로 Excel 검증을 실행하는 방법을 설명합니다.

## 1. 준비할 파일

두 개의 `.xlsx` 파일이 필요합니다.

### 직원 목록
필수 의미 컬럼:
- 직원 ID: `EmployeeID`, `사번`, `직원ID`, `직원번호` 등
- 이름: `Name`, `이름`, `성명`, `직원명` 등
- 부서 코드: `DepartmentCode`, `부서코드`, `조직코드` 등
- 이메일: `Email`, `이메일`, `메일` 등

### 부서 마스터
필수 의미 컬럼:
- 부서 코드: `DepartmentCode`, `부서코드`, `조직코드` 등
- 부서명: `DepartmentName`, `부서명`, `조직명` 등
- 관리자: `Manager`, `부서장`, `관리자`, `담당자` 등

컬럼 순서는 달라도 됩니다. 지원되는 별칭은 자동으로 표준 컬럼에 매핑됩니다.

## 2. Windows GUI 사용법

1. `excel-validator-gui.exe`를 실행합니다.
2. **직원 목록**에서 첫 번째 Excel 파일을 선택합니다.
3. **부서 마스터**에서 두 번째 Excel 파일을 선택합니다.
4. 결과 저장 위치를 확인하거나 바꿉니다.
5. **검증 실행** 버튼을 누릅니다.
6. 완료되면 전체/정상/오류 건수가 표시됩니다.
7. **결과 파일 열기** 버튼으로 생성된 Excel을 바로 확인합니다.

## 3. 결과 파일

결과 Excel에는 세 개의 시트가 생성됩니다.

- `Result`: 전체 데이터 + 매칭된 부서 정보 + 검증 상태
- `Errors`: 오류 데이터만 별도 정리 + 권장 조치
- `Summary`: 전체/정상/오류 및 오류 유형별 건수

대표 검증 상태:

- `OK`: 정상
- `DUPLICATE_ID`: 직원 ID 중복
- `MISSING_DEPT_CODE`: 부서 코드 누락
- `UNKNOWN_DEPT`: 부서 마스터에 없는 코드

## 4. 실행파일 받는 곳

GitHub 저장소의 **Actions → Build Windows EXE → 성공한 실행 → Artifacts**에서
`excel-validator-windows`를 내려받습니다.

압축 안에는 다음 두 파일이 포함됩니다.

- `excel-validator-gui.exe`: 일반 사용자용
- `excel-validator-cli.exe`: 명령행/자동화 연계용

## 5. 자주 발생하는 오류

### 필수 컬럼이 없다고 나오는 경우
현재 지원되는 컬럼 별칭이 아닌 이름일 수 있습니다. 실제 외주에서는 고객 파일에 맞춰 컬럼 매핑 규칙을 추가할 수 있습니다.

### 같은 의미의 컬럼이 두 개 있는 경우
예: `EmployeeID`와 `사번`이 동시에 존재하면 어느 컬럼이 기준인지 모호하므로 오류로 중단합니다. 하나만 남기거나 별도 규칙을 정해야 합니다.

### 결과 파일이 열리지 않는 경우
Excel에서 기존 `result.xlsx`를 열어둔 상태라면 저장이 실패할 수 있습니다. 파일을 닫고 다시 실행합니다.

## 6. 데이터 안전

이 프로그램은 선택한 로컬 Excel 파일을 로컬에서 읽고 결과 파일을 생성합니다.
현재 데모에는 외부 서버 업로드나 고객 데이터 전송 기능이 없습니다.

저장소의 샘플 데이터는 전부 더미 데이터이며 실제 회사·고객 데이터를 포함하지 않습니다.
